Entry format: **date (ET)** · docs reviewed · gaps found · actions (PR / `docs-gap` issue).
Gaps go to Integration as a small docs PR labelled `needs-review:I` or an issue labelled `docs-gap`. Interface changes (APIs, DB schema, shared UI) are announced in an issue labelled `interface-change` **before** merge.
