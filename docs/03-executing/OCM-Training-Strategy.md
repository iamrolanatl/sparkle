## 1. Change Approach
Reduce overwhelm. Training emphasizes Today, focus mode, and how Sparkle assists without replacing effort. Follows progressive disclosure and grade-8 reading level.

## 2. Audiences & Interventions
| Audience | Need | Intervention | Timing |
|---|---|---|---|
| Students | Know next priority, focus, Sparkle | Short in-app guidance; optional Sparkle intro; sharing/access list explainer | First run |
| Parents | Invite, sharing limits, shopping list, comms confirmation | Invitation flow guidance; one-page parent guide | Invitation |
| Support / Ops | Admin console, diagnostics, audit, view-as rules, escalation | Admin runbooks linked from health alerts; walkthrough | Before G5 |

## 3. Materials
In-app tooltips + progressive disclosure; one-page parent guide; admin runbooks; agent install guide (Windows/macOS) *(added)*.

## 4. Success Measures
Activation (first sync + student linked), next-action completion, support ticket volume — targets **TBD (Rolan)** in KPI dashboard.

## 5. Resistance & Feedback
In-app feedback, support tickets, and UAT findings reviewed at sprint review; adoption issues logged in RAID.
